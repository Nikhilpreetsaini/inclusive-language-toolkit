# Contributing Guidelines

Thank you for considering contributing to Inclusive Language Toolkit! We welcome contributions that make the project better for everyone. To ensure a smooth process, please follow these guidelines.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Install dependencies** using `pip install -r requirements.txt`.
3. **Create your feature or bug fix** in a descriptive branch name.
4. **Add tests** for any new features and ensure existing tests still pass.
5. **Run the test suite** using `pytest`.
6. **Submit a pull request**, ensuring your description clearly states the problem and solution.

## Code Style

- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/) style guidelines.
- Use meaningful variable and function names.
- Include docstrings for all public functions and modules.

## Pull Request Process

- Keep pull requests focused and concise.
- Describe what changes were made and why.
- Reference any relevant issues by number.
- Ensure that your code passes CI checks.

## Reporting Issues

Please use the issue tracker to report bugs or suggest improvements. Provide as much detail as possible, including steps to reproduce the issue.

## Community

Be respectful and inclusive in your communications. All interactions are governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
